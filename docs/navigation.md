# Finding your way around

RemotePower has a lot of pages — 89 of them, across twelve domains. This page is
about the four ways to get to one, and when each is the right one.

## All pages — the map

The **All pages** button at the top of the sidebar opens a single screen with
every page on it, grouped by domain, each with a one-line description of what it
answers. Type to filter; Enter opens the first match.

Use it when you do not yet know what the thing you want is called. The sidebar
shows one domain at a time and the command palette needs a search term, so
neither helps when the question is "what is even in here?".

The list is built from the sidebar itself, so it is never out of date, and a page
your installation has switched off is simply not in it.

## The sidebar

Twelve domains. **More than one can be open at once** — clicking a domain header
toggles it, and the set is remembered. *Expand every sidebar group* (in the All
pages dialog) opens all twelve, and opens them again into a tidy rail if they are
already open.

Navigating to a page opens its domain, and leaves the other domains you
opened exactly as they were.

**Star a page** to pin it to the top of the sidebar, above the domains.

## The command palette — `Ctrl-K` or `/`

For when you know what you want. It searches pages, devices, open alerts, CVE
findings and actions, so `reboot`, `terminal` or a hostname all work. It is the
fastest route once the product is familiar.

## The sidebar search box

Searches page titles *and the concepts they contain* — typing `SLA`, `cron` or
`metrics` finds the page that handles them even when the word is not in its name.

## Which to use

| You want to | Use |
|---|---|
| See what exists | **All pages** |
| Jump somewhere you know | **Ctrl-K** |
| Find the page that handles a concept | the sidebar **search box** |
| Return to the handful you use daily | **starred** entries |

## Not finding a page at all?

Some pages belong to optional modules — Alerts, Tickets, Billing, the Knowledge
Base, Compliance, Pentest and Autonomy can each be switched off under
**Settings → Advanced**. A module that is off hides its nav entry *and* answers
its whole API with a not-found, so the page is absent rather than
merely hidden. Turn it back on there.

If you are signed in with a restricted role, pages outside your permissions do
not appear either.
