# RemotePower v8.0.0 — "Pil0tMatters"

The first release of a new major version. It changes what you can adjust in the interface and what the agent finds on its own. Production runs 7.5.0, and everything on this page is new since then; [CHANGELOG.md](../CHANGELOG.md) has the full list.

You can set the text size from 80% to 300%, show a long page as tabs or as one page, and keep up to eight named layouts for Home. Ten setup tasks have a wizard, and six long dialogs can show a few fields at a time. The Linux agent finds the apps a host runs, out of the 63 it knows, and offers a monitor and a connector for each. Three connectors, an Apprise destination, four monitor types (SMTP, IMAP, SSH banner and NTP), a read-only MCP endpoint, automatic image updates with a rollback and a Traffic view of what each Linux host talks to are new. Reading the whole code once more found one High issue and several Medium ones, all fixed; they are listed at the end.

## After you upgrade

- Hard-reload the dashboard once so the new front end loads.
- **Update the agents.** The agent version is 8.0.0. Finding apps, running the new monitor types from a host, rolling back an image update, the push mark and reading Suricata's logs happen on the host.
- **Long pages open as tabs.** Thirteen pages that stacked many blocks on one scroll show one group at a time. To get the long page back, choose **One long page** under **My Account → Appearance → Page sections**; the choice is kept in your browser.
- **A host in quarantine or in maintenance mode refuses Run command, an Ansible run and the web terminal.** All three ignored it before.
- **Four things are off until you switch them on:** the MCP endpoint and Traffic (both under Settings → Advanced → Optional modules), automatic image updates (Containers → Image updates) and log lines in an unhealthy container's alert (Monitoring → Tuning).
- **Settings → Alerts inbox has a new switch**, *Let every signed-in user acknowledge, resolve and assign alerts*. It is on, as it was; turn it off to limit those actions to administrators.

## The interface

**Text size.** The user menu has a *Text size* row with a smaller and a larger button, and **My Account → Appearance** has ten steps from 80% to 300%. A window too narrow for a step holds the largest steps back: 200% at most on a window 1,440 pixels wide and 110% on a phone. A dialog still fits in the window at 300% and a menu opens next to its button. The old *Interface size* setting kept its stored value.

**Tabs.** Thirteen more pages show one group at a time, as Threat Intel, My Account, Sites and Reports have since 7.4.0: Server Status, Compliance, Live Monitor, Patches, Tuning, Network, Pentest, SSH Gateway, Autonomy, KMIP, Tickets, CVE Findings and Containers.

**Layouts for Home.** Under *Customize → Layouts* you keep up to eight named layouts next to your own. Make one from a copy, from one of four ready-made ones (Fleet overview, Security, Patching and Capacity) or from an empty one. *Copy wall display link* gives a link that shows each layout in turn. The fleet heat map can group its cells by group, site, OS, host type, agent version or status, and colour them by health score, worst finding, pending updates or last check-in.

**Wizards.** *Guide me* opens a wizard for a host, a notification destination, an integration, e-mail, single sign-on, the syslog, flow and satellite sidecars, the push channel and the SSH gateway. Each one checks as it goes. The host wizard waits for the host to check in, the notification wizard sends a test and shows the answer, and the e-mail and sign-on guides test with the settings you typed before anything is saved. A **Step by step** switch at the top of six long dialogs (maintenance window, monitor target, backup job, auto-patch policy, rollout and host profile) shows the same form a few fields at a time. See [wizards.md](wizards.md).

**Smaller changes.** A *Time display* setting reaches tables, cards and sentences. A cron schedule is also written as a sentence. A call that fails over the network says why. Every page has a heading a screen reader can find, and the browser tab names the page. Controls are at least 24 pixels across. The README pictures and the tour are drawn again in the Pilot look, and the public demo opens in it.

## Apps and connections

**Apps found on a host.** The Linux agent reads the listening sockets, the containers and the running services and says which of 63 well-known apps it found. The host drawer lists them under *Discovered on this host*, and each one offers **Monitor** and **Connect** (the integration wizard, with the address and port filled in). An app is recognised by a process name, a container image or a service; a port counts only when it belongs to one app or another sign agrees. Nothing is probed and nothing is made by itself. See [app-discovery.md](app-discovery.md).

**Connectors.** Tailscale, Headscale and Cloudflare Tunnel are new. The Pi-hole, Immich, Proxmox Backup Server, Paperless, Syncthing, ESPHome, Grafana, Sonarr family and UniFi connectors read more of what their products report, from the vendors' own API descriptions. The UniFi connector speaks the Integration API, and a TrueNAS that no longer has the REST API says so instead of showing "HTTP 404".

**Monitors.** SMTP, IMAP, SSH banner and NTP check that a service answers as it should: the greeting, the server's abilities, an encrypted session, the clock's offset. No mail is sent and nobody logs in. They run from the server, from a Linux host's agent or from a satellite.

**Notifications.** Apprise is a destination of its own, for the services behind one URL. An unhealthy container's alert can carry the container's last log lines (0 to 10, off by default); passwords and tokens are masked and the lines are not stored.

**MCP endpoint.** `POST /api/mcp` answers the Model Context Protocol on the server, so a client that can send a header connects without a local file. It is read-only, off until you switch it on, and offers the 16 read tools of the bridge. Each question runs as the calling API key, so the key's scope, addresses, expiry and rate limit apply. See [mcp.md](mcp.md).

**Automatic image updates.** The Image updates tab can update the images you list, in shadow mode first. A change that needs approval is parked, maintenance mode and quarantine apply, and a failed update raises an `image_autoupdate_failed` event. An option rolls a project back to its previous images when the check after the update finds an unhealthy container.

**Traffic.** Tick **Traffic** under Settings → Advanced → Optional modules and each Linux agent starts reading its established TCP connections with `ss`, once a minute by default. **Network → Traffic** and the host drawer show which addresses each host talks to, which programs open the connections and how much each one moved, with a country and organisation when GeoLite2 is set up. An address a host first used after its first hour is marked **New**. A watch list of addresses, networks, ports and programs raises a **Watched connection** alert; only the platform operator edits it. A host that cannot be read says why. The Data Explorer has a `traffic` entity and Fleet Query has **Talks to**. No packet is captured and no payload is read. See [traffic.md](traffic.md).

## Found by reading the whole code

- **High.** The host drawer's settings form read nine fields from a list that never carried them, so a save cleared the host's command allowlist, watched units and files, log rules and SSH mode. It reads the host's own settings now.
- **Medium.** The AI executor could not propose a script from your library, and an approval row never named one: three readers took the script library for a dictionary when it is a wrapped list. Run command, an Ansible run and the web terminal ignored quarantine or maintenance mode; they ask the same question as the command queue now.
- **Also fixed.** A busy store answered 500 where 6.1.2 meant 503. Passkey sign-in and the sign-in callbacks read the proxy's scheme header five different ways. Four places lost a colour or a dimming when the inline styles were removed. Editing a backup monitor reset the fields its form does not show. The kiosk cycle skipped nine pages and logged a refused fullscreen request as an error.
